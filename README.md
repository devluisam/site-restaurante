# Restaurante — Landing page

Landing page institucional para um restaurante — página única em HTML, CSS e JavaScript,
sem framework e sem etapa de build.

> **Peça demonstrativa.** O nome, os textos e os números da página são fictícios e
> servem apenas para demonstrar o layout. Não representam um cliente real.

**Demo:** https://site-restaurante-rho-ten.vercel.app

## O que a página traz

- Layout responsivo, de 360px a telas largas
- Navegação fixa com rolagem suave entre seções
- Seções de apresentação, serviços, equipe e contato
- SEO on-page: `title`, `description` e Open Graph para pré-visualização em links
- Animações de entrada discretas, acionadas por `IntersectionObserver`
- Chamada direta para WhatsApp

## Tecnologias

HTML5 · CSS3 (custom properties, grid e flexbox) · JavaScript sem dependências

## Como executar

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```
